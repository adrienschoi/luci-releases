# Luci for Mac

Downloads for Luci, a menu bar app that notices when you're working and gives you a short heads-up when your attention slips.

Luci is invite-only for now: you need the invite code from your invitation.

## Install

1. Download **Luci-x.y.dmg** from the [latest release](https://github.com/adrienschoi/luci-releases/releases/latest) (under *Assets*).
2. Open the DMG and drag **Luci** to **Applications**.
3. Open Luci and enter your invite code.

Requires macOS 14 or later.

## Update

Download the newest DMG from the same link and drag it to Applications again, replacing the old copy. Your history and settings stay.
